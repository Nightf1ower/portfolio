# Font Panic fonts

Upload 10–20 font files into this folder.

Supported formats:
- `.woff2`
- `.woff`
- `.ttf`
- `.otf`

The game loads every supported font in this folder automatically. File names are used only for internal identification, so simple names such as `font-01.woff2`, `font-02.ttf`, and so on are recommended.

Do not delete this README unless at least one font file is already present, otherwise GitHub will remove the empty folder.
